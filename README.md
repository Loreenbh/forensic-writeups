# Forensic & Security Writeups

This repository contains structured security analysis writeups focused on understanding system behavior, attack techniques, and incident investigation from a SOC / DFIR perspective.

The goal is not only to solve security challenges, but to reconstruct what happened, how it happened, and how it can be detected or mitigated.


## Objectives

- Understand system-level behavior during security incidents
- Analyze attack techniques and compromise methods
- Reconstruct incident timelines and root causes
- Develop structured thinking for SOC / DFIR investigations

## Approach

Each write-up follows a consistent investigation methodology:

1. **Detection** – identifying abnormal behavior or suspicious activity  
2. **Context analysis** – understanding the environment and entry point  
3. **Technical investigation** – analyzing binaries, logs, or system behavior  
4. **Root cause identification** – explaining how the compromise works  
5. **Key takeaways** – lessons for detection and prevention
